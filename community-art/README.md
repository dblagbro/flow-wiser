# Flow-wiser community artwork

![Flow-wiser community open-source meme](flow-wiser-keep-it-going-900.webp)

This humorous community-recruitment artwork was created for the unofficial
`dblagbro/flow-wiser` continuation fork.

## Assets

`flow-wiser-keep-it-going.png` is the canonical large-format original. The WebP
files are derived from it — use those for web and README display, and the PNG as
the print/source master.

| File | Size | Use |
| --- | --- | --- |
| `flow-wiser-keep-it-going.png` | 1254x1254, 2.4 MB | **Canonical source master** — print, remixing, high-DPI |
| `flow-wiser-keep-it-going.webp` | 1254x1254, 363 KB | Full-resolution web delivery |
| `flow-wiser-keep-it-going-900.webp` | 900x900, 225 KB | Default README / docs display |
| `flow-wiser-open-source-meme.webp` | 450x450, 42 KB | Compact inline / social thumbnail |

Note: this artwork is a community rally poster, not an application icon. It is
deliberately text-heavy and does not reduce legibly to favicon size.
